Datenschutzerklärung – Aion Homelab

Stand: 30. September 2026

Wer nutzt die Anwendung?

„Aion Homelab“ ist eine private Anwendung für eine einzelne Person, den Betreiber. Sie wird weder angeboten noch verkauft und ist für Dritte nicht nutzbar.

Welche Google-Daten werden abgerufen?

Mit ausdrücklicher Zustimmung des Betreibers liest die Anwendung dessen eigenes Gmail-Postfach über die Gmail-API mit dem Berechtigungsumfang gmail.readonly (nur lesen). Es werden keine Mails gesendet, gelöscht, verändert oder markiert.

Wo werden die Daten gespeichert?

Abgerufene Nachrichten werden ausschließlich auf einem privaten Server im Heimnetz des Betreibers gespeichert und dort von einem lokal laufenden Sprachmodell verarbeitet. Es werden keine Daten an Dritte oder an Cloud-KI-Dienste weitergegeben, verkauft oder für Werbung verwendet.

Einhaltung der Google-Richtlinien

Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Lokal gespeicherte Daten löscht der Betreiber auf seinem eigenen Server.

English summary: Aion Homelab is a private, single-user application. It reads only the owner's own Gmail mailbox (read-only scope) with the owner's consent and stores the data exclusively on the owner's private home server. No data is shared, sold, sent to third parties or used for advertising. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
